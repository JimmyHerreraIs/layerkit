# Security policy

## Supported versions

layerkit is in early development (pre-1.0). Only the latest release receives
security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for a security problem.

Report it privately through GitHub:

1. Go to the [Security tab](https://github.com/JimmyHerreraIs/layerkit/security) of this repository.
2. Choose **Report a vulnerability**.
3. Describe the problem, the version you used, and how to reproduce it.

You can expect an acknowledgement within a few days. Once the problem is
confirmed and fixed, it will be credited in the release notes unless you prefer
to stay anonymous.

## Scope

layerkit processes images locally and does not send them anywhere. Problems
worth reporting include, for example, crashes or unsafe behavior triggered by a
crafted image file, and path handling issues when writing the output files.
